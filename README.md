A single Wi-Fi network name, 32 characters or fewer, that lands a joke and implies a whole story in the few words a passer-by sees in a phone's network list. This entry writes **"My Ex Still Pays For This"** (25 characters) — a breakup, a bill never cancelled, and a petty victory, all in five deadpan words. The program is fully deterministic: it always writes the same single name to `/output/entry.txt`.

## Run it

```sh
node main.ts
```
